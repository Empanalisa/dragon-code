# First Dragon: Byteena

## Dragon Attributes
* Name: Byteena
* Color Scheme: Purple/Pink
* Type: Memory (Malloc Metropolis)
* Rarity: Common

## Obtaining and Hatching Egg
* Cost: 20 coins (1 correct answer = 10 coins)
* Hatching: Player clicks "Hatch Egg" to purchase and reveal the dragon.

## Collection Display
* Before Hatching: Displays egg
* After Hatching: Displays fully hatched dragon
