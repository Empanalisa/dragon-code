# 🐉 Code & Conquer

A game that teaches CS1 topics. Players explore a kingdom map, solve coding challenges in each village, earn coins, and hatch dragons.

## How it works
- Each village = one CS1 topic
- Answer challenges correctly → earn coins
- Spend coins on eggs → hatch dragons
- Finish a village → unlock the next one
